# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This is a data science playground for experimenting with the modern Python data stack. The repository demonstrates migration from traditional Python data science tools to their Rust-powered successors: `polars` (replacing pandas), `ruff` (replacing black), `uv` (replacing pyenv/pip), `marimo` (replacing jupyter), and `FastAPI` (replacing flask).

The playground includes examples using in-memory analytical engines:
- **DuckDB**: Relational database for analytical queries
- **Kuzu**: Property graph database for graph analytics
- **LanceDB**: Vector database for embeddings

## Technology Stack

- **Package management**: `uv` (Python >=3.12)
- **Task runner**: `just` (justfile for common tasks)
- **Notebooks**: `marimo` (reactive Python notebooks, not Jupyter)
- **DataFrames**: `polars` (Rust-based, replacing pandas)
- **Visualization**: `altair` for declarative visualizations
- **Databases**: `kuzu`, `duckdb` for in-memory analytics
- **Linting**: `ruff` (configured in pyproject.toml with marimo language server)
- **Containers**: `podman` for running services

## Common Commands

### Environment Setup
```bash
# Clone and install dependencies (first time)
uv sync

# Run Python code with uv
uv run python <script>.py

# Run marimo notebooks
uv run marimo edit <notebook>.py
```

### Working with Kuzu Graph Database
```bash
# Load data into Kuzu database (run at least once to create local database)
just kuzu-load-data

# Launch Kuzu Explorer UI (runs on http://localhost:8000)
just kuzu-explorer

# Show installed package sizes
just show-project-size
```

## Marimo Notebooks

All `.py` files in the root are marimo reactive notebooks, not regular Python scripts. Marimo notebooks:
- Use `@app.cell` decorators for each cell
- Have automatic dependency tracking between cells
- Must be run with `uv run marimo edit <file>.py`
- Can be converted to standalone scripts with `if __name__ == "__main__": app.run()`

When creating or editing marimo notebooks:
1. Always use the `@app.cell` decorator pattern
2. Return variables in tuples to make them available to other cells
3. Use `mo.md()` for markdown documentation cells
4. Can hide code with `@app.cell(hide_code=True)`

## Key Patterns

### Polars DataFrame Pattern
```python
import polars as pl

# Read and transform data
df = (
    pl.read_csv("path/to/file.csv")
    .with_columns(
        pl.col("date").str.to_date("%Y-%m-%d")
    )
    .filter(pl.col("value") > 0)
)
```

### Kuzu Graph Database Pattern
```python
import kuzu

# Connect to database
db = kuzu.Database("path/to/database.kz")
conn = kuzu.Connection(db)

# Execute Cypher queries
result = conn.execute("MATCH (u:Users)-[r:Ratings]->(m:Movies) RETURN u, r, m")

# Convert to NetworkX for analysis
G = result.get_as_networkx(directed=False)
```

### Altair Visualization Pattern
```python
import altair as alt

# Create interactive visualizations
chart = (
    alt.Chart(df)
    .mark_line()
    .encode(x="date:T", y="value:Q")
    .properties(width=800, height=400)
)
```
